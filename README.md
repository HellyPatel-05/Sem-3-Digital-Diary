# Sem-3-Digital-Diary

This project is a Python-based Digital Diary application built using Tkinter for the GUI and MySQL for user authentication. It allows users to register, log in, and securely write personal diary entries. Each entry includes a date, mood, and content, which is encoded using a simple shift cipher before being saved to a text file for privacy. The application also provides features like forgot password, viewing and decoding saved diary entries, and a user-friendly multi-page interface.
